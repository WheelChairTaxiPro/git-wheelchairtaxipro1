## 4. Malicious Click Reduction Strategy  

## 4. 惡意點擊減少策略

**EN:**  
While it is not possible to directly stop Google from charging for clicks, we implement a multi-layer strategy to significantly reduce invalid or low-quality traffic:

**Google Ads Optimisation**

- IP exclusions based on detected suspicious activity
- Negative keywords to filter non-customer intent (e.g., “free”, “job”)
- Location targeting (focus on local service areas only)
- Ad scheduling (limit high-risk time periods)
- Call-focused campaigns to prioritise real enquiries

**Website & Tracking Layer**

- Detect repeated visits from same IP/device
- Identify very short sessions and no-interaction behaviour
- Assign a “suspicious score” to each visit
- Maintain a blacklist of high-risk IPs/devices

**Bot & Spam Protection**

- Rate limiting and bot filtering
- CAPTCHA / Turnstile for forms
- Basic web application firewall (e.g., Cloudflare)

**Conversion Optimisation**

- Track only meaningful actions (calls, form submissions)
- Improve data quality for Google Ads optimisation
- Optional offline conversion tracking (link real bookings back to ads)

**Outcome:**

- Reduce wasted ad spend
- Improve real customer conversion rate
- Provide evidence for optimisation and reporting

**中文：**  
雖然無法直接阻止 Google 對每次點擊收費，但我們會透過多層策略，有效減少無效或低質量流量：

**Google 廣告優化**

- 根據可疑活動封鎖 IP
- 使用否定關鍵字（例如「免費」、「工作」）
- 限定投放地區（只針對本地服務範圍）
- 設定廣告時段（避免高風險時間）
- 使用電話優先廣告，提高真實查詢

**網站及追蹤層**

- 偵測同一 IP / 裝置的重複訪問
- 識別極短停留及無互動行為
- 為每個訪客計算「可疑評分」
- 建立高風險 IP / 裝置黑名單

**防機器人及防垃圾流量**

- 流量限制及機器人過濾
- 表單驗證（CAPTCHA / Turnstile）
- 基本網站防護（例如 Cloudflare）

**轉換優化**

- 只追蹤真正有價值的行為（電話、表單）
- 提升 Google 廣告數據質素
- 可選離線轉換追蹤（將實際訂單連結回廣告）

**效果：**

- 減少廣告浪費
- 提升真實客戶轉換率
- 提供數據支持優化決策
