# Wheelchair Taxi Website & Platform Proposal
## 輪椅的士網站及平台建議書

---

## 1. Project Overview | 項目概覽

**EN**  
This proposal outlines the development of a modern, mobile-friendly website and lightweight application platform for Wheelchair Taxi services. The goal is to increase bookings, reduce advertising waste, and provide a seamless customer experience.

The official domain to be used for this project will be: **wheelchairtaxipro.com**.

**中文**  
本建議書旨在為輪椅的士服務建立一個現代化、支援手機的網站及輕量應用平台，以提升訂單數量、減少廣告浪費，並提供流暢的用戶體驗。

本項目將使用的官方網址為：**wheelchairtaxipro.com**。

---

## 2. Objectives | 目標

**EN**
- Enable instant customer contact (Call, WhatsApp, etc.)
- Capture user location automatically
- Reduce invalid or malicious ad clicks
- Improve Google search visibility (SEO)
- Provide a scalable foundation for future expansion

**中文**
- 提供即時聯絡（電話、WhatsApp 等）
- 自動獲取用戶位置
- 減少無效或惡意廣告點擊
- 提升 Google 搜尋排名（SEO）
- 建立可擴展的系統基礎

---

## 3. Key Features | 核心功能

### 3.1 One-Click Contact | 一鍵聯絡
**EN**: Users can instantly contact drivers via Phone, WhatsApp, LINE, or WeChat.  
**中文**：用戶可一鍵透過電話、WhatsApp、LINE 或 WeChat 聯絡司機。

### 3.2 Location Detection | 定位功能
**EN**: Automatically detect user location to simplify booking.  
**中文**：自動獲取用戶位置，方便填寫接送地點。

### 3.3 Installable Web App (PWA) | 可安裝應用（PWA）
**EN**: Users can install the website as an app on mobile and desktop.  
**中文**：用戶可將網站安裝到手機或電腦，像應用程式一樣使用。

### 3.4 Basic Booking System | 基本預約系統
**EN**: Users can submit booking requests with pickup details.  
**中文**：用戶可提交預約請求及接送資料。

### 3.5 Anti-Fraud Protection | 防止惡意點擊
**EN**:
- IP tracking
- Click frequency limiting
- Google Ads conversion tracking

**中文**：
- IP 記錄
- 點擊頻率限制
- Google 廣告轉換追蹤

---

## 4. Technical Architecture | 技術架構

**Frontend**: Angular (Mobile-first design)  
**Backend**: .NET Web API  
**Hosting**: Cloud (Azure / Alternatives)  
**Maps**: Google Maps API

---

## 5. Hosting Comparison | Hosting 比較

### Option A: Microsoft Azure
**EN**:
- Pros:
  - Highly scalable
  - Strong integration with .NET
  - Enterprise-level reliability
- Cons:
  - Higher cost
  - More complex setup

Estimated Cost:
- Small project: NZD $20–$80/month
- With backend & scaling: NZD $100+/month

**中文**：
- 優點：
  - 高擴展性
  - 與 .NET 完美整合
  - 高穩定性
- 缺點：
  - 成本較高
  - 設定較複雜

預計成本：
- 小型項目：約 NZD $20–$80/月
- 含後端及擴展：約 NZD $100+/月

---

### Option B: Cloudflare + Static Hosting
**EN**:
- Pros:
  - Very low cost or free
  - Fast global CDN
- Cons:
  - Limited backend support

Estimated Cost:
- NZD $0–$10/month

**中文**：
- 優點：
  - 成本極低或免費
  - 全球高速 CDN
- 缺點：
  - 後端功能有限

預計成本：
- 約 NZD $0–$10/月

---

### Option C: VPS (e.g., DigitalOcean)
**EN**:
- Pros:
  - Balanced cost and flexibility
- Cons:
  - Requires manual management

Estimated Cost:
- NZD $10–$40/month

**中文**：
- 優點：
  - 成本與彈性平衡
- 缺點：
  - 需要自行管理

預計成本：
- 約 NZD $10–$40/月
